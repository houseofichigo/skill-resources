# Source registry

Use this registry to route live searches. It records access and reuse constraints;
it does not bundle third-party content. Verify the current repository or site terms
when a record will be quoted or adapted.

## Supplementary sources

### AI Visual Prompt Cookbook

- URL: `https://github.com/VigoZhao/AI-Visual-Prompt-Cookbook`
- Best for: reusable style systems, prompt improvement, variables, fidelity anchors,
  composition and negative prompts.
- Rights: code, scripts and documentation are MIT; `style.json` prompt content is
  CC BY 4.0; preview images are reference-only.
- Use: quote or adapt prompt content only with credit, licence link, and change note.

### Awesome GPT-4o Images

- URL: `https://github.com/jamez-bondos/awesome-gpt4o-images`
- Best for: GPT-4o and GPT Image 1 transformation, editing and composition patterns.
- Rights: repository-original material is generally CC BY 4.0, with OpenAI notices
  and case-level overrides. Check each case's `ATTRIBUTION.yml` or notice before use.

### Awesome GPT Image 2 Prompts

- URL: `https://github.com/no-chili/awesome-gpt-image-2-prompts`
- Best for: GPT Image 2 prompts with structured metadata and visual references.
- Rights: the maintainer's compilation, metadata and documentation are CC BY 4.0;
  third-party prompts, preview images, names and source posts may remain reserved.
- Use: retain canonical record, original creator, source URL, licence, and change note.
  Do not mirror the dataset.

### Image Prompt Library

- URL: `https://github.com/EddieTYP/image-prompt-library`
- Best for: architecture patterns for local storage, provenance, tags, collections,
  backups and private prompt management.
- Rights: application code is AGPL-3.0-or-later; sample packs have separate terms.
- Use: do not treat this application as a primary prompt corpus. Do not copy its code
  into this MIT skill.

### Midlibrary

- URL: `https://midlibrary.io/`
- Terms: `https://midlibrary.io/midlibrary/terms-of-use`
- Best for: current Midjourney styles and SREF discovery.
- Rights: its terms restrict copying, modification, distribution and derivatives of
  visual content without written permission.
- Use: live-reference only. Link users to the original page. Do not ingest, cache,
  mirror, redistribute, or reproduce preview images.

## Query construction

Build queries only from the user's request. Examples:

- `site:github.com/YouMind-OpenLab gpt image 2 product poster prompt`
- `site:github.com/VigoZhao/AI-Visual-Prompt-Cookbook editorial typography`
- `site:github.com/no-chili/awesome-gpt-image-2-prompts cinematic product`
- `site:github.com/jamez-bondos/awesome-gpt4o-images image editing composition`

Open the resulting primary file or canonical record and verify it directly.
