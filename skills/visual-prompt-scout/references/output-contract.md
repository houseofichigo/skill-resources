# Output contract

## Find mode

Start with one line naming the medium, target model and live sources checked.

For each of up to three safe candidates provide:

1. title and source link;
2. creator and retrieval date when available;
3. exact prompt or a short excerpt only when rights permit;
4. why it fits the request;
5. preview link when reuse and linking are permitted;
6. injection status;
7. licence or rights note.

Never silently mix candidates. Ask whether the user wants one adapted only when a
selection would materially affect the result; otherwise recommend the strongest one.

## Improve or port mode

Return:

- **Target:** medium, model, format and purpose.
- **Source patterns:** three attributed candidates and the transferable structures
  learned from each. Use short excerpts rather than reproducing rights-reserved text.
- **Improved prompt:** one self-contained prompt, clearly labelled as adapted or
  original.
- **Changes:** concise list of material improvements and model-specific choices.
- **Safety:** injection status and anything removed.
- **Provenance:** source links, creator, licence scope and retrieval date.

## Prompt construction checklist

For images, consider subject, action, environment, composition, camera, lens,
perspective, lighting, colour, material, texture, typography, aspect ratio, reference
handling, exclusions and output intent.

For video, add shot sequence, duration, frame rate when supported, camera movement,
subject continuity, temporal changes, environmental motion, pacing, transitions,
ending frame and supported audio direction.

Do not add every field mechanically. Include only details that reduce ambiguity or
improve control for the target model.
