# Platform procedure

1. Resolve current identity, selected company, published release and allowed role. Stop if any is unavailable.
2. Read the exact authorized source and revision. Display extraction failures and missing evidence explicitly.
3. Preview proposed changes. Separate exact source quotations, attributed statements, questions and unverified proposals. Never copy canonical approvals or tasks into editable authoritative prose.
4. For a requested mutation, obtain explicit confirmation of its preview and pass the expected version and stable retry key to the approved operation. A retry never changes its payload.
5. Recheck access before returning or exporting evidence. Source change or revocation requires a new read; never use a denied cached result.
6. Report the saved source/revision IDs and sanitized outcome. Failures preserve originals and current validated content. External vendor execution is unverified.

Original uploads: private, at most 20 files and 20 MB per file. Record individual outcomes. Exact-byte matches are duplicate candidates, never automatic merges. Extracted previews are not proof of factual accuracy.

Wiki authoring: AI is optional and returns a proposal only. The user must save a draft, then separately validate the exact revision. Restoration creates a draft; stale source evidence requires reconciliation before validation.
