# Interview: ask little, remember everything

Always the host question tool (never a list in chat): ≤4 questions per call, 2–4 options each, options named after what discovery found, `multiSelect` where several fit. **Every question has "You choose for me"**; when there is a clear best answer, put it first and mark "(Recommended)". If the tool is unavailable, ask the same questions in one short numbered message with the defaults stated.

## Step 0: saved profile?
Read `<path>/PROFILE.md` before asking anything. Reuse Owner choices; say in one line what you reused ("Using your saved profile: <...>"). Ask only what is new.

## Round B: this run
<Table: the variant (from references/<variants>.md), the format/length, the one message (written from their own copy), and any deliverable-specific choice.>
Then, if the variant needs facts you do not have (a price, a date, a quote), ask for them exactly; never invent them. Then ask for assets in one `multiSelect` question.

## Don't ask
- What the files already answer: <colours, fonts, logo, claims>.
- What the saved profile already answers.
- Taste you can show instead — make sample frames and let them react.
- The default itself — apply it, say so, move on.

## When the user is away or says "just go"
Use the saved profile, else the recommended options; write them under "Assumed, not asked"; say so in one line; continue. Show a checkpoint (sample/outline) as soon as it exists.
