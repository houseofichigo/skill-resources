# Discovery: learn the brand before producing a frame

The output is judged against the brand's own look. Collect it first, write it into `PROFILE.md`, treat it as law. All four paths below must converge on the same profile.

## First: is there a saved profile?
Look for `<path>/PROFILE.md`. If it exists, it is the brand — refresh only what changed, then go to the interview.

## Four starting points
- **A brand folder / a design skill** (<e.g. an approved design skill, tokens file, or brand book>): read it all; it is the law.
- **A codebase:** run 3–4 read-only sweeps in parallel (rules & voice; tokens; components; the real content the output will show). Return paths, values and quotes — not opinions.
- **A URL only:** capture it <how>, then read the capture like a brand folder. A blocked or partial capture is a HARD STOP — ask for the brand files, do not guess.
- **Nothing:** the brand round of the interview, "You choose for me" on every question; read the logo they send for its colours.

## Write PROFILE.md
Fill every section. Cite the source of each rule (file path or owner quote). Mark defaults as defaults so the owner can overrule them.

## Stop when
You can state <the brand's core message in n statements> and name <palette, fonts, logo, the claims boundary>. Then run the interview.
