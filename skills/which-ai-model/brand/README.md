# Brand assets

House of Ichigo design tokens and logo, used by `infographic/which-ai-model.html`.

- `tokens.css` — colour, type and layout custom properties (imports the fonts below)
- `fonts-embedded.css` — self-hosted Manrope, Inter Tight, JetBrains Mono and
  IBM Plex Sans Arabic, base64
- `hoi_lockup_cobalt_rgb.png` — logo lockup

The skill itself has no dependency on any of this. If you fork the repo and want your
own look, replace these files and re-render the infographic.
