# Skill Repo Forge

Find, audit, improve, install and package portable Agent Skills. The workflow keeps inspection, repair, installation and publication as separate, evidence-backed stages.

Created by [House of Ichigo](https://houseofichigo.com). Equipped to run.

## Repository

- Standalone repository: [houseofichigo/skill-repo-forge](https://github.com/houseofichigo/skill-repo-forge)
- Collection copy: [skill-resources/skills/skill-repo-forge](https://github.com/houseofichigo/skill-resources/tree/main/skills/skill-repo-forge)

## Install

From the standalone repository:

```bash
npx skills add houseofichigo/skill-repo-forge --skill skill-repo-forge
```

From the House of Ichigo skills collection:

```bash
npx skills add houseofichigo/skill-resources --skill skill-repo-forge
```

The upload-ready archive is [`dist/skill.zip`](dist/skill.zip). The canonical Skill begins at [`SKILL.md`](SKILL.md).

## Verification

The publication candidate passes cross-host static validation, distribution synchronisation, and six repository layout tests. Static checks do not prove runtime behavior on every agent host.
