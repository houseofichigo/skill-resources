# Vibe Prompt Architect

Turn a raw app or feature idea into a refined, tool-specific build prompt for vibecoding and AI app builders.

- Preserved source: [`archives/2026-09-27/vibe-prompt-architect-import/manifest.json`](../../../../archives/2026-09-27/vibe-prompt-architect-import/manifest.json)

The skill supports quick mock-ups and spec-driven real development for Lovable, Replit, v0, Bolt, Cursor, Windsurf, Base44, and similar tools. It verifies volatile tool guidance live and can incorporate named component-registry patterns into the resulting prompt.

Install from the canonical repository:

```bash
npx skills add houseofichigo/vibe-prompt-architect --skill vibe-prompt-architect
```
