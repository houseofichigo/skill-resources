# Asset guide

| Family | Brief must resolve |
|---|---|
| Sales and proposals | buyer context, requirements, evaluation criteria, offer, proof, objections, deliverables, commercial next step |
| Training | learners, prerequisites, outcomes, sequence, exercises, produced artifacts, assessment, facilitator requirements |
| Reports and diagnostics | evidence set, dimensions, findings logic, recommendations, risks, roadmap, validation ownership |
| Website and campaigns | audience, intent, message hierarchy, proof, page or channel structure, conversion path, CTA |
| Product and platform | persona, job, journey, data, system behavior, states, edge cases, metrics, acceptance tests |
| Agents and automation | use case, trigger, inputs, tools, authority, memory, human review, outputs, failures, monitoring, tests |
| Internal operations | owner, audience, decision rights, source of truth, workflow, handoff, review and maintenance |

For any family, prefer an existing approved template or schema over this generic guide. Record the template version and do not imply that a draft has been approved.
